# Archiwum

Rzeczy wycofane ze strony, zachowane na wypadek powrotu. Nic stąd nie jest częścią
builda ani deployu (`npm run build` nie czyta tego katalogu).

| Katalog | Co to jest |
| --- | --- |
| [`prediction/`](prediction/README.md) | Model prognoz progów i zapełnienia pul (dane CEM LEK/LDEK, backtesty, pilotaż placówek i geografii, skrypty, skill `cmkp-cem-data-refresh`). |
| [`seo-subpages/`](seo-subpages/README.md) | Statyczne podstrony `/specjalizacje/<slug>/` wycofane z SEO. |
| [`results-j-2022/`](results-j-2022/README.md) | Lista zakwalifikowanych z jesieni 2022 (PDF + CSV), której strona nie pokazuje. |
